### Added

- Add the `register_storages` plugin hook for registering custom external snapshot backends from installed plugins and `conftest.py` files. Expose `Storage`, `ExternalLocation`, and `StorageLookupError` through `inline_snapshot.plugin`.
- Allow storage backends to short-circuit comparisons through an optional `lazy_compare()` method. Its `StorageValue` argument provides the original value and a lazily serialized temporary file path, which is reused for updates. Backends defining this method also use it in disabled snapshot mode.
